# Мои полезные привычки — регистрация по email

Это **серверная часть в разработке**, не включённая на действующем сайте. Для настоящих кабинетов необходимы PostgreSQL и SMTP (рассылка писем подтверждения).

## Запуск на Timeweb Cloud
1. В существующем Timeweb-аккаунте создать PostgreSQL. Использовать защищённое соединение (TLS) или приватную сеть.
2. Подключить SMTP-ящик с разрешённой отправкой подтверждающих писем.
3. Создать **новое backend-приложение Express** в App Platform из репозитория, указать ветку `family-habits-registration` и директорию `/server`. Для постоянного адреса и cookie предполагается размещение фронтенда и сервера **на одном домене**, поэтому сервер также отдаёт статические файлы родительского проекта.
4. Настроить переменные из `.env.example` только в панели Timeweb (не в GitHub).
5. Протестировать подтверждение email, восстановление пароля, вход, состояние семьи и сохранение рисунков. Пригодность для настоящих детских данных требует проверки информационной безопасности и юридических документов.

## Важные принципы
- Аутентификация родителей, а не детей. Детям отдельные email не нужны.
- Все запросы к данным фильтруются по идентификатору владельца серверной сессии.
- Пароли хэшируются bcrypt; токены и сессии — SHA-256.
- Пользовательские файлы рисунков хранятся в PostgreSQL (bytea). Большие объёмы позднее можно перенести в S3.
- Не подключать без тестирования к действующей базе и не выдавать демоверсию за готовый публичный сервис.
